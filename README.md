# Personal Portfolio Website

A modern, responsive, and clean personal portfolio website designed to showcase my professional identity, skills, and projects.

## 🚀 Features

- **Responsive Design:** Fully optimized for all devices, from mobile phones to large desktop monitors, using the **Bootstrap 5 Grid System**.
- **Modern UI/UX:** A sleek, professional interface with a focus on readability and user experience.
- **Interactive Elements:** Integrated **Typed.js** for a dynamic typing effect in the hero section, adding a professional touch.
- **RTL Support:** Fully optimized for Persian (RTL) language layout using **Bootstrap 5 RTL**.
- **Typography:** Utilizes the high-quality **Vazirmatn** font for a clean and modern Persian typography.

## 🛠️ Technologies Used

- **HTML5:** Semantic structure for better SEO and accessibility.
- **CSS3:** Custom styling and layout enhancements.
- **Bootstrap 5 (RTL):** For rapid, responsive, and grid-based layout development.
- **JavaScript:** For interactive components and animations.
- **Typed.js:** For the dynamic typing effect.
